Conceptos básicos del desarrollo web

¿Qué es una página web?

Una página web es un documento digital que se puede consultar mediante un navegador, como Google Chrome, Firefox o Microsoft Edge. Puede contener texto, imágenes, videos, enlaces y otros elementos.

¿Cómo funciona una página web?

Cuando un usuario escribe una dirección web, el navegador solicita los recursos al servidor correspondiente. El servidor responde enviando los archivos necesarios y el navegador los interpreta para mostrar la página.
HTML se utiliza para organizar y estructurar el contenido de una página web.

Páginas web estáticas

Son páginas cuyo contenido permanece igual hasta que alguien modifica sus archivos. Generalmente se construyen con HTML y son apropiadas para mostrar información fija, como una presentación personal o una página informativa.

Páginas web dinámicas

Son páginas cuyo contenido puede cambiar según las acciones del usuario, los datos almacenados o la información recibida de un servidor. Pueden utilizar bases de datos y lenguajes de programación.

Diferencia entre sitio web y aplicación web

Un sitio web es un conjunto de páginas relacionadas que comparten una dirección o dominio y presentan información sobre un tema, organización o servicio.

Una aplicación web permite realizar tareas interactivas, como enviar formularios, administrar información, realizar compras o gestionar cuentas de usuario.
Por ejemplo, una página universitaria informativa es un sitio web, mientras que un sistema de matrícula en línea es una aplicación web.
